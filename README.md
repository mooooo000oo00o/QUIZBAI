# 🧠 QuizBai

QuizBai is a fun and interactive quiz game designed to test and improve a player's knowledge through multiple-choice questions. Players can enter their name, answer questions, receive instant feedback, track their progress, and view their final score.

The app also saves the highest score and the name of the player who achieved it, making the quiz more fun and competitive.

## ✨ Features

* 👋 Player name input
* 📝 Multiple-choice quiz questions
* ✅ Correct and wrong answer feedback
* 📊 Progress bar
* ⭐ Score tracking
* 🏆 Highest score and highest player
* 💾 Saves highest score using AsyncStorage
* 🎉 Final result screen
* 🔄 Play Again feature
* 📱 Mobile-friendly interface
* 🎨 Simple and colorful game-style design

## 🛠️ Technologies Used

* React Native
* Expo
* TypeScript
* AsyncStorage
* JavaScript/React concepts

## 🚀 How to Run

1. Clone this repository.

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

2. Open the project folder.

```bash
cd QuizBai
```

3. Install the dependencies.

```bash
npm install
```

4. Start the Expo development server.

```bash
npx expo start
```

5. Open the app using Expo Go or an available emulator.

## 🎮 How to Play

1. Enter your name.
2. Press **Start Quiz**.
3. Read each question carefully.
4. Choose your answer.
5. Check your feedback.
6. Continue until all questions are completed.
7. View your final score.
8. Try again and beat the highest score!

## 🎯 Purpose of the Project

QuizBai was created as a school project to practice mobile application development, React Native components, TypeScript, state management, and data storage using AsyncStorage.
